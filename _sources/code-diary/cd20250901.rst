ifPresent

OrElse
OrElseGet
map

filter

这些方法过了一遍,就有一个大概的印象.

总结:不返回null,避免扩散.
如果一个结果可能不存在,就用 Optional来返回.
如果"不存在是一个异常'就通过 Excepiton来处理,而不是  返回 Optional再判断isEmpmty
避免将 Optional 作为方法参数:增加调用者负担
避免将 Optional 作为方法成员:会是的序列化和并发处理变复杂.
