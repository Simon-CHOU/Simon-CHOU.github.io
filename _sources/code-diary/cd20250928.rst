对谈
----------------------
亲人认为“五年还不出头，你出不了头了”。我不服但是无法立刻证伪这个观点。只能忍气吞声。
tasking和velocity，尤其是velocity是我最严重的问题。我所有的进度都太慢了：学新技术慢，跳槽慢，晋升慢，准备面试慢，升学慢，婚育慢，攒钱慢。
我一定做错了什么。我现能立刻想到的词就是“自律 self dicipline"。我所有的东西都tasking出来，但是执行时就想打折扣，或者中途分身。
过往我被评价过”半途而废“-”出工不出活“， 就是tasking-velocity这个课题下的问题。
上学时我还能隔山差五练习，但是上班了自己生活就常常忘记，或者觉得“顺其自然也无所谓，放过自己”。这种散漫贻害无穷。
